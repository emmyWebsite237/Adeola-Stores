Workflows & integrations

How an order actually moves through Sokoni — from the moment you tap Place order to the parcel in your hands — and the systems that make it happen. Everything below is a demonstration setup.

End-to-end

The order lifecycle

One connected chain. Each step fires automatically and notifies the next system, so nothing waits on a human unless it needs to.

Exception path

Failed payment, out-of-stock or a failed delivery attempt pauses the order and raises a task for support.

Returns branch

A return request re-opens the order, books a pickup and issues either a refund or a replacement.

Feedback loop

Delivery times, return reasons and review sentiment feed back into stock planning.

Accounts

Sign-up → verify → login → account

The customer account journey, from a first-time visitor to a dashboard holding order history. In this demo it runs entirely in the browser — no server, no data transmitted.

Try it yourself
Forgot password

A reset link takes the customer to a new-password screen, then straight back to sign in — without support ever getting involved.

Session & sign-out

Signing in starts a session stored locally; the header switches to an account chip and signing out clears it.

Stored in your browser

Profile, addresses and orders live in localStorage only. Nothing is posted anywhere — this is a demonstration storefront.
